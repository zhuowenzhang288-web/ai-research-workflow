# IDEA_REPORT：自进化 agent 的"真变强"评测

## 1. 真实任务与代表工作（论文事实，摘要级）

任务：agent 可在线修改自身代码/提示词/配置后，其能力增益能否被可信归因为"真的变强"，而非评测过拟合或隐性退化。

代表工作（arXiv 检索，未通读正文）：
- **DGM**（2505.22954）：迭代自修改代码，用 SWE-bench 等 benchmark 验证每次改动。
- **ADAS/Meta Agent Search**（2408.08435）：meta-agent 编程新 agent，公开 benchmark 上报增益并声称跨域迁移。
- **Fragility of Self-Improving Agents**（2608.18066）：再评估记忆式自改进 agent，指出评测噪声大、任务顺序敏感——与本题最接近，但只覆盖记忆式方法、只重评不建协议。
- 相邻：Skill-Policy 共演化陷阱（2610.20845，揭示在最终 skill bank 上评分的盲点）；GuardrailLoop（2609.12216，偏安全审计）。

## 2. 现有评测默认了什么、哪里不成立

1. **目标即分布**：打分集代表部署任务。不成立：部署分布私密且非平稳；公开题可能已进训练数据（污染）。
2. **分数可信**：benchmark 分=能力增益。不成立：自修改循环可直接朝评分函数优化（刷榜）；单次运行方差大（2608.18066）。
3. **只看目标能力**。不成立：改代码/提示词可能悄悄破坏未监控的辅助能力（指令遵循、安全、工具鲁棒性），即未发现退化。
4. **无成本口径**：部署中 token/时延是硬约束。

## 3. 研究问题、假设、差异

- **RQ1（过拟合缝隙）**：公开集 B 上进化的增益，多少迁移到全程不可见的去污染 held-out B'？缝隙=B 增益−B' 增益。
- **RQ2（隐性回归）**：被接受的代际中，多少在固定 canary 套件上超噪声阈值退化？
- **RQ3（协议）**：旋转私密评测+canary+成本记账能否低成本预测缝隙？

假设（待验）：H1 缝隙>0 且随代数增大；H2 回归率不可忽略，与 benchmark 增益存在 trade-off；H3 小 held-out+廉价 canary 约 1/10 预算即可预测缝隙。

差异：DGM/ADAS 提方法报增益，本工作测量增益中的过拟合成分与回归，不立新方法；比 2608.18066 多了 held-out 去污染与 canary 两条诊断轴，且对象是自改代码/配置的 agent；与 2610.20845/2609.12216 正交互补。

## 4. 最小验证路径

1. 基线：开源 meta-agent 框架（ADAS 实现或简化 DGM 循环），固定后端 LLM 与预算，先跑未改动基线。
2. 进化赛道：允许改 system prompt+工具代码，打分用公开集 B（SWE-bench Verified 子集 100 题或 MBPP），B 对进化全程可见。
3. Held-out B'：改写+新造平行题（或取训练截止后新题），去污染，仅终评。
4. Canary：固定约 50 题（指令遵循、安全、通用 QA、工具使用），每代必测。
5. 规模：约 10 代 × 3 种子（响应方差批评），记录 B/B'/canary 三分数与 token。
6. 产出：缝隙曲线、逐代回归率、协议成本；按 H1–H3 标 supported/invalidated。

风险：单框架外推有限，定位为协议可行性验证，小规模已验证与待大规模实测分开陈述。
