# F3 探针报告：Voyager (arXiv:2305.16291) 核心实验数字核验

**核验来源**：arXiv 官方 HTML 全文（v2，2023-10-19 修订版，https://arxiv.org/html/2305.16291v2）。以下所有数字均直接摘自原文，未凭记忆填写。论文基线方法：ReAct、Reflexion、AutoGPT；所有探索实验最多 160 次 prompting 迭代，每组 3 次试验。

## 一、摘要级核心结论（原文 Abstract）

| 指标 | 数值 |
|---|---|
| 发现独特物品数 | **3.3×** 于先前 SOTA |
| 行进距离 | **2.3×** 于先前 SOTA |
| 解锁关键技术树里程碑速度 | 最快 **15.3×** 于先前 SOTA |

## 二、探索进度（正文 3.3 节，Fig. 1）

- Voyager 在 **160 次 prompting 迭代内发现 63 种独特物品**，为基线的 **3.3 倍**。
- 各基线明显落后：AutoGPT 发现新物品显著偏少；ReAct、Reflexion 几乎无实质进展（附录 B.4.1 列出每轮试验物品清单，例如 ReAct 三次试验仅得 4/4/2 种物品）。

## 三、技术树掌握（Table 1，最多 160 次迭代，3 次试验取均值）

单位：所需 prompting 迭代次数（越少越快）；括号内为成功次数/3。

| 方法 | 木质工具 | 石质工具 | 铁质工具 | 钻石工具 |
|---|---|---|---|---|
| ReAct | 0/3 未解锁 | 0/3 | 0/3 | 0/3 |
| Reflexion | 0/3 | 0/3 | 0/3 | 0/3 |
| AutoGPT | 92±72 (3/3) | 94±72 (3/3) | 135±103 (3/3) | 0/3 |
| Voyager w/o Skill Library | 7±2 (3/3) | 9±4 (3/3) | 29±11 (3/3) | 0/3 |
| **Voyager** | **6±2 (3/3)** | **11±2 (3/3)** | **21±7 (3/3)** | **102 (1/3)** |

- 解锁速度对比（相对最优基线 AutoGPT）：木质 **15.3×**、石质 **8.5×**、铁质 **6.4×** 更快。
- **Voyager 是唯一解锁钻石等级技术树的方法**（3 次试验中成功 1 次，平均 102 次迭代）。
- 注：消融行 "w/o Skill Library" 在铁质层快于完整 Voyager（29±11 vs 21±7），原文如此，属跨试验正常波动。

## 五、零样本泛化到新世界的未见任务（Table 2，最多 50 次迭代，3 次试验）

四个任务：钻石镐、金剑、岩浆桶、指南针。清空背包、换全新世界后从零开始。

| 方法 | 钻石镐 | 金剑 | 岩浆桶 | 指南针 |
|---|---|---|---|---|
| ReAct / Reflexion / AutoGPT | 均 0/3 | 均 0/3 | 均 0/3 | 均 0/3 |
| AutoGPT + Voyager 技能库 | 39 (1/3) | 30 (1/3) | 0/3 | 30 (2/3) |
| Voyager w/o 技能库 | 36 (2/3) | 30±9 (3/3) | 27±9 (3/3) | 26±3 (3/3) |
| **Voyager** | **19±3 (3/3)** | **18±7 (3/3)** | **21±5 (3/3)** | **18±2 (3/3)** |

- Voyager 是**唯一全部任务 3/3 成功**的方法；且借用其技能库后 AutoGPT 成功率由 0 提升至部分成功（体现技能库可即插即用）。

## 六、消融实验（3.4 节，Fig. 9；共消融 6 项设计）

| 消融项 | 对"发现物品数"的影响 |
|---|---|
| 自动课程 → 随机课程 | **下降 93%** |
| 自动课程 → 人工课程（挖矿钻的 10 步固定流程） | 不如自动课程（仅定性结论，无百分比） |
| 移除技能库 | 后期进展停滞/平台化（定性） |
| 移除自验证（self-verification） | **下降 73%**（三类反馈中最重要） |
| 代码生成 GPT-4 → GPT-3.5 | 独特物品数 **降为 1/5.7（即 GPT-4 多 5.7×）** |

其他配置事实：卡住后最多 4 轮代码生成即换任务；GPT-4 API 费用约为 GPT-3.5 的 15 倍。

## 七、技能检索精度（附录 Table A.4，309 个样本）

- Top-1：80.2±3.0；Top-2：89.3±1.8；Top-3：93.2±0.7；Top-4：95.2±1.8；**Top-5：96.5±0.3**（提示中即取 top-5 相关技能）。
- 检索时用 GPT-3.5 生成任务建议 + 环境反馈作为查询；技能库以 text-embedding-ada-002 嵌入为键的向量数据库存储。

## 八、实验设置（3.1 节）

- 模型：gpt-4-0314 + gpt-3.5-turbo-0301；embedding：text-embedding-ada-002；温度全为 0，仅自动课程用 0.1。
- 环境：MineDojo + Mineflayer JS API；附录 B.4.5 显示换用 gpt-4-0613 性能大致相同。

## 未能核验 / 原文未给出单一数值的事项

1. **技能库最终技能总数**：原文未给出一个"总计 N 个技能"的单一数字（仅提到随机课程是从 Voyager 获得的 **101 种物品**中随机抽取任务；技能库随探索持续增长）。网上流传的"某个固定技能总数"在此版本原文中**未能核验**。
2. **行进距离的绝对数值**（方块数/米数）：原文只报告 2.3× 倍率，**未能核验**绝对距离。
3. 探索曲线的逐点数值（Fig. 1/7/9 为图像）：除 63 种物品、3.3×/2.3×/15.3×/8.5×/6.4×/5.7× 等文中明写数字外，曲线中间点数值**未能核验**。
