# Q4 争议地图：agent 记忆研究

你是科研助手。围绕"LLM agent 的长期记忆/经验管理"这一方向，画一张争议地图，写入 `IDEA_REPORT.md`。

**要求**：
1. 共识区：多项独立研究支持的结论及其适用范围。
2. 分歧区：冲突结果与各自证据；可能解释（数据/评测/模型/预算）标清谁是假设。
3. 候选空白：论文指出的 limitation/future work、尚待解决的问题；不得因自己没找到就断言无人研究。
4. 逐篇列 Limitation/Future Directions 的要点；原文没单列就注明，不编造。
5. 回答：空白值不值得做？现有数据/算力/方法能否切入？

可用网络检索，用不到就标注。800 字内，写入 `IDEA_REPORT.md`。时间预算 15 分钟。
