## 已核验的 5 篇

### 1. A-MEM: Agentic Memory for LLM Agents
- **arXiv**：2502.12110（2025-02-17 提交，v11；NeurIPS 2025）
- **第一作者**：Wujiang Xu（Rutgers University）
- **关键数字（论文报告）**：在 DialSim 数据集上 F1 = **3.45**，比 LoCoMo 方法的 2.55 高 **35%**、比 MemGPT 的 1.18 高 **192%**（论文 §4.3 / Table 2）。
  - 另可引用：LoCoMo 上 GPT-4o-mini 的 Temporal 类 F1 = 45.85（MemGPT 为 25.52）；token 用量比 LoCoMo/MemGPT（约 16,900）降低 **85–93%**。
- **核验来源**：arXiv abs 页 + HTML 全文 v11（Table 1/2/3、§4.3 原文核对）。

### 2. Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory
- **arXiv**：2504.19413（2025-04-28 提交，v1）
- **第一作者**：Prateek Chhikara
- **关键数字（论文报告）**：在 LoCoMo 基准上，LLM-as-a-Judge 指标比 OpenAI 系统相对提升 **26%**；p95 延迟降低 **91%**、token 成本节省 **超过 90%**（摘要原文）。
- **核验来源**：arXiv abs 页摘要原文。

### 3. MemoryOS（Memory OS of AI Agent）
- **arXiv**：2506.06326（2025-05-30 提交，2025-06 发布）
- **第一作者**：Jiazheng Kang
- **关键数字（论文报告）**：LoCoMo 基准、GPT-4o-mini 下，对基线的平均提升为 F1 **+49.11%**、BLEU-1 **+46.18%**（摘要原文）。
- **核验来源**：arXiv 官方检索页返回的该文摘要原文（arXiv:2506.06326）。

### 4. MIRIX: Multi-Agent Memory System for LLM-Based Agents
- **arXiv**：2507.07957（2025-07-10 提交）
- **第一作者**：Yu Wang
- **关键数字（论文报告）**：LOCOMO 基准 **85.4%**（声称 SOTA）；ScreenshotVQA 上比 RAG 基线准确率高 **35%** 且存储需求降低 **99.9%**（摘要原文）。
- **核验来源**：arXiv 官方检索页返回的该文摘要原文（arXiv:2507.07957）。

### 5. MIRIX-2.0: Multi-Agent Memory System（2026 年条目）
- **arXiv**：2611.12068（2026-11-09 提交）
- **第一作者**：Wei-Chieh Huang
- **关键数字（论文报告）**：LoCoMo **91.4%**；LongMemEval-S **72.6%**，领先最强基线 **14.3** 个百分点（摘要原文）。
- **核验来源**：arXiv 官方检索页返回的该文摘要原文（arXiv:2611.12068）。

## 一句话小结（我方观察，非论文事实）
