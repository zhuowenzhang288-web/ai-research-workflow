# F1 探针报告：LLM Agent 长期记忆/经验管理（2025–2026）5 篇代表性工作

**核验方式**：以下编号、作者均通过 arXiv 官方 API（export.arxiv.org）按 ID 回查标题/作者逐一确认；
关键数字均取自 arxiv.org 摘要页或论文 HTML 正文原文，未凭印象填写。

---

## 1. A-MEM: Agentic Memory for LLM Agents
- **arXiv**：`2502.12110`（v1 提交 2025-02-17；NeurIPS 2025 接收，当前 v11）
- **第一作者**：Wujiang Xu
- **关键数字（原文核验）**：在 DialSim 数据集上 F1 = **3.45**，较 LoCoMo 方法（2.55）**提升 35%**、较 MemGPT（1.18）**高 192%**（论文正文原文："achieving an F1 score of 3.45 (a 35% improvement over LoCoMo's 2.55 and 192% higher than MemGPT's 1.18)"）；另报告每次记忆操作约 1,200 tokens，token 用量较 baseline（16,900 tokens）降低 **85–93%**。

## 2. Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory
- **arXiv**：`2504.19413`（v1 提交 2025-04-28）
- **第一作者**：Prateek Chhikara
- **关键数字（摘要原文核验）**：LOCOMO 基准上 LLM-as-a-Judge 指标较 OpenAI 记忆方案**相对提升 26%**；p95 延迟降低 **91%**；token 成本节省 **超过 90%**。

## 3. MemOS: A Memory OS for AI System
- **arXiv**：`2507.03724`（v1 提交 2025-07-04，当前 v4）
- **第一作者**：Zhiyu Li
- **关键数字（论文 Table 3 原文核验）**：LoCoMo 基准（统一 GPT-4o-mini 基座）Overall = **75.80**，高于最强 baseline Memobase 的 72.01（Mem0 64.57、Zep 59.22）；系统层面在 100 QPS 压力下保持 **100% 成功率**。

## 4. HippoRAG 2: From RAG to Memory — Non-Parametric Continual Learning for Large Language Models
- **arXiv**：`2502.14802`（v1 提交 2025-02-20；ICML 2025，当前 v2）
- **第一作者**：Bernal Jiménez Gutiérrez（OSU NLP Group）
- **关键数字（摘要原文核验）**：关联记忆（associative memory）任务上较 SOTA 文本嵌入模型**提升 7%**，同时在事实性记忆与理解（sense-making）任务上优于标准 RAG。

## 5. MemArena: An Ego-Centric Benchmark for On-Device Agentic Personal Memory Assistants at Scale
- **arXiv**：`2608.02613`（v1 提交 2026-05-20；NeurIPS 2026 Evaluations & Datasets Track，当前 v2）
- **第一作者**：Jiadong Zhang
- **关键数字（摘要原文核验）**：Qwen3-8B 上把记忆后端从 Memobase 换成 MemSearch，内容准确性指标提升 **+22.1/+21.2 个百分点**（而把 reader 从 8B 扩到 32B-AWQ 最多仅 +3.5/+4.4 pp）；模拟规模为 50 agents × 15 天、10.3M 对话 tokens。
