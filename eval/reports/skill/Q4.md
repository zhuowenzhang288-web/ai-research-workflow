# Q4 争议地图：LLM Agent 长期记忆/经验管理

**检索说明**：15 分钟定向核查（arXiv 摘要页 + 已知文献）。已核验：MemGPT(2310.08560)、LoCoMo(2402.17753)、Mem0(2504.19413)、A-MEM(2502.12110)。LongMemEval 与记忆机制综述检索超时/编号不符，未核验，相关陈述标 [未核验]。

## 1. 共识区

| 结论 | 适用范围 | 证据 |
|---|---|---|
| 长上下文 LLM 长程记忆不可靠：时间/因果推理远逊人类，长上下文与朴素 RAG 仅部分改善 | ~300 turn、9K token 级多会话 QA | LoCoMo [事实] |
| 外部记忆成本显著优于全量上下文（p95 延迟 −91%、token −90%） | 事实型长记忆、生产部署 | Mem0 [事实] |
| 分层/显式记忆架构已成主流范式（OS 式虚拟上下文、向量检索、结构化笔记网络） | LoCoMo 类会话基准上报告优于基线 | MemGPT、A-MEM、Mem0 [事实] |

## 2. 分歧区

1. **参数化 vs 非参数化记忆**：一方报告 LoRA 持续预训练可接近甚至超过 RAG [MASC，未核验]；Mem0/A-MEM 报告外部记忆大幅领先。可能解释：任务类型、写入预算、基准单一——[假设]。
2. **图记忆增益大小**：Mem0+graph 仅 +2% [事实]；A-MEM 报告显著增益 [事实]。可能解释：图 schema、链接构建质量、评测集不同——[假设]。
3. **反思式经验记忆**（Reflexion 类）：静态 QA 有效，在线交互任务收益不稳定、或随轮数递减——[假设，本轮未查]。

## 3. 候选空白（逐篇自列 Limitation / Future Work）

- **LoCoMo**：模型长程时间/因果理解远不及人类（作者明示）；合成+人审数据，真实长对话泛化未验。
- **Mem0**：评测仅 LoCoMo 单基准、LLM-as-judge；摘要称将扩展更多基准（正文 limitation 未核）。
- **A-MEM**：记忆组织依赖 LLM 调用、写入成本高；主要验证于会话 QA，未在长程 agent 任务（OS/Web/代码）系统验证 [分析]。
- **MemGPT**：仅文档分析、多会话聊天两域；检索依赖手工函数设计 [分析]。
- **LongMemEval** 指 LoCoMo 题型少、有答案泄漏风险、缺强推理更新题 [未核验]。

## 4. 判断

**值不值得做**：值得。评测口径混乱（单基准 + LLM 裁判）是明确痛点；"写入策略 × 遗忘曲线 × 任务类型"的受控对比在检索范围内无系统结论——注意：这仅是"未找到"，不等于无人研究。
**能否切入**：能。LoCoMo 等数据公开；可在 Mem0/A-MEM 开源实现上改；成本为 API 级调用，无需训练预算。下一步：按 §2 三轮查新确认空白后，提交一页纸 IDEA_REPORT 供确认。
