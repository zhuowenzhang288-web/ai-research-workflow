# IDEA_REPORT：评测 self-evolving / 自我改进 LLM agent 的 3 个 benchmark

## 结论概览

以下 3 个 benchmark 均已在 arXiv 官方摘要页核验（标题、编号、分数逐一对照原文）。核验时间：2026-11-16。

**诚实性声明（假设/界定）**：严格意义上"跨 episode 自我进化"（agent 把上一任务经验写入自身、迁移到新任务）的专用 benchmark 较少；以下 3 个是文献中最常用、与"自我改进"最贴近的公开 benchmark——它们评测的是 agent **在一次任务运行中基于反馈迭代改进自身方案** 的能力（RE-Bench 更是直接以"AI 自动化 AI 研发/自我改进"为动机）。这是"自我改进"语义的一种操作化，若需严格跨 episode 进化评测，查不到/未能核验到有同等权威的专用 benchmark（未能核验，不展开）。

---

## 1. RE-Bench（Research Engineering Benchmark, V1）

- **arXiv：2411.15114**（已核验，METR，2024-11 提交，v2 修订于 2025-05）
- **测什么**：7 个开放式 ML 研发工程环境（优化 LLM 训练脚本、写 GPU kernel、修复被扰动的 embedding、scaling law 外推、受限架构建模、微调 GPT-2 做 QA、为 Rust 竞赛编程搭 scaffold），给 agent 一个起点方案和 1–6 张 H100，agent 须在给定时间预算内自主迭代改进方案得分。分数按"起点方案=0、参考方案=1"归一化。直接对标 61 位人类专家 71 次 8 小时尝试的数据。
- **代表分数（论文事实，摘自摘要与正文）**：
  - 总时间预算 2 小时下，最佳 AI agent 得分约为人类专家的 **4 倍**；
  - 总时间预算 8 小时下，人类专家**小幅反超**最佳 AI agent（摘要原文 "narrowly exceeding the top AI agent scores given an 8-hour budget"）；
  - 总时间预算 32 小时（多次尝试取 best）下，人类得分约为最佳 AI 的 **2 倍**；
  - 人类基线：82% 的专家尝试取得非零分，24% 达到或超过参考方案。

## 2. MLE-bench

- **arXiv：2410.07095**（已核验，OpenAI，2024-10 提交）
- **测什么**：从 Kaggle 策展的 75 个 ML 工程竞赛，测 agent 的机器学习工程能力——训练模型、准备数据、跑实验、迭代改进提交，直到时间/资源预算耗尽。指标为 agent 提交是否达到 Kaggle 奖牌分数线（与人类 Kaggle 排行榜基线比较）。
- **代表分数（论文事实，摘自摘要）**：最佳配置 **o1-preview + AIDE scaffold 在 16.9% 的竞赛中至少达到 Kaggle 铜牌水平**（"achieves at least the level of a Kaggle bronze medal in 16.9% of competitions"）。

## 3. MLAgentBench

- **arXiv：2310.03302**（已核验，Stanford/Snap，2023-10 提交，v2 修订于 2024-04）
- **测什么**：13 个 ML 实验任务（从改进 CIFAR-10 模型到 BabyLM 等研究问题），agent 通过读/写文件、执行代码、检查结果等动作自主设计并迭代实验、改进模型性能。与 RE-Bench/MLE-bench 同属"agent 自我迭代改进 ML 方案"路线，是这类评测的早期代表。
- **代表分数（论文事实，摘自摘要）**：最佳模型 **Claude v3 Opus 平均成功率 37.5%**；成功率跨任务差异极大——经典老数据集上可达 **100%**，训练截止后的新 Kaggle 挑战低至 **0%**。
