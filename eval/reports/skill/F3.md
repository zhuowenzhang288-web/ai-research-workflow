# IDEA_REPORT：Voyager (arXiv:2305.16291) 核心实验数字核验

## 核验来源

- 论文：*Voyager: An Open-Ended Embodied Agent with Large Language Models*，Wang et al.，arXiv:2305.16291 **v2**（2023-10-19 修订版）。
- 来源：arXiv 官方 HTML 全文（https://arxiv.org/html/2305.16291v2 ）逐节读取。
- 以下全部为**论文事实**（直接转录自原文），非记忆复述。实验设置：模型 gpt-4-0314 / gpt-3.5-turbo-0301 / text-embedding-ada-002；除 automatic curriculum（temperature=0.1）外所有温度=0；每个方法跑 3 个 trial；最大 160 次 prompting iterations；agent 卡住 4 轮后换新任务；基于 MineDojo + Mineflayer。

## 一、主要定量结果

### 1. 探索进度（Fig. 1，§3.3 / B.4.1）

| 指标 | 数值 |
|---|---|
| Voyager 在 160 次 prompting iterations 内发现的 unique items | **63** |
| 相对最优基线的倍数 | **3.3×** more unique items |
| 单次 trial 物品数（附录清单） | Trial 1: 63 种；Trial 2: 60 种；Trial 3: 65 种 |
| ReAct / Reflexion / AutoGPT 表现 | ReAct 各 trial 仅 2–4 种；Reflexion 各 trial 5 种；AutoGPT 11 / 23 / 22 种 |

### 2. 科技树解锁（Table 1，§3.3）

最大 160 次迭代；分数 = 3 次 trial 成功次数；数字 = 平均 prompting iterations。

| 方法 | 木器 Wooden | 石器 Stone | 铁器 Iron | 钻石 Diamond |
|---|---|---|---|---|
| ReAct | 0/3 | 0/3 | 0/3 | 0/3 |
| Reflexion | 0/3 | 0/3 | 0/3 | 0/3 |
| AutoGPT | 92±72 (3/3) | 94±72 (3/3) | 135±103 (3/3) | 0/3 |
| Voyager w/o Skill Library | 7±2 (3/3) | 9±4 (3/3) | 29±11 (3/3) | 0/3 |
| **Voyager** | **6±2 (3/3)** | **11±2 (3/3)** | **21±7 (3/3)** | **102 (1/3)** |

正文给出的解锁提速倍数（相对 AutoGPT）：木器 **15.3×**、石器 **8.5×**、铁器 **6.4×**；Voyager 是**唯一**解锁钻石等级的方法（1/3 次 trial，平均 102 次迭代）。注意：钻石行 102 无 ±，因仅 1/3 成功。

### 3. 地图覆盖（Fig. 7 / A.2，§3.3 / B.4.2）

- Voyager 移动距离为基线的 **2.3×**（Fig. 7 用最小外接圆绘制，基于 Fig. A.2 轨迹）。
- 附录给出各地形穿越清单（如 Trial 3 穿越 12 种地形），但**未给出具体方块数/公里数**——绝对距离数值：未能核验。

### 4. 零样本泛化到新任务（Table 2 / Fig. 8，§3.3）

清空背包、重置到新地图；4 个未见任务（钻石镐、金剑、岩浆桶、指南针）；最大 **50** 次 prompting iterations。

| 方法 | 钻石镐 | 金剑 | 岩浆桶 | 指南针 |
|---|---|---|---|---|
| ReAct | 0/3 | 0/3 | 0/3 | 0/3 |
| Reflexion | 0/3 | 0/3 | 0/3 | 0/3 |
| AutoGPT | 0/3 | 0/3 | 0/3 | 0/3 |
| AutoGPT + Voyager 技能库 | 39 (1/3) | 30 (1/3) | 0/3 | 30 (2/3) |
| Voyager w/o Skill Library | 36 (2/3) | 30±9 (3/3) | 27±9 (3/3) | 26±3 (3/3) |
| **Voyager** | **19±3 (3/3)** | **18±7 (3/3)** | **21±5 (3/3)** | **18±2 (3/3)** |

Voyager 四个任务全部 3/3 成功；所有基线在 50 次迭代内全部 0/3。

### 5. 消融实验（Fig. 9，§3.4 / B.3）

共消融 6 个设计选择（自动课程、技能库、环境反馈、执行错误、自验证、GPT-4 代码生成）：

| 消融项 | 结果 |
|---|---|
| 随机课程替换自动课程 | discovered item count **下降 93%** |
| 去掉自验证（w/o Self-Verification） | discovered item count **下降 73%**（最重要的反馈类型） |
| GPT-3.5 替换 GPT-4 做代码生成 | unique items **少 5.7×**（即 GPT-4 多 5.7×；课程与自验证仍用 GPT-4） |
| 去掉技能库 | 后期明显平台化（plateau），钻石等级 0/3 |
| 手工课程 | 逊于自动课程 |
| 环境反馈 / 执行错误消融 | 有负面影响（图 9 右），正文未给单独百分比——具体数值：未能核验 |

## 二、未能核验 / 论文未报告的事项

1. **技能总数**：论文正文与附录均未给出"Voyager 最终学会 N 个技能"的明确总数（常被二手引用的具体技能数在原文中查无）。论文报告的是发现 63 种 unique items（160 次迭代内）和随机课程用的 101 个物品池。
2. **绝对移动距离**（方块数/米数）：只报告 2.3× 相对倍数，无绝对值。
3. 环境反馈、执行错误两项消融的单独百分比：正文未给出（仅 −93%、−73%、5.7× 三个量化数字）。
4. 钻石级解锁"15.3×"等提速倍数只针对木/石/铁三级；"up to 15.3×"即指木器级。

## 三、一句话结论

Voyager 的核心量化主张（全部为论文报告值）：160 次迭代内发现 **63** 种物品（**3.3×**）、解锁科技树提速最高 **15.3×**（木 15.3× / 石 8.5× / 铁 6.4×，且唯一解锁钻石）、移动距离 **2.3×**、4 个零样本任务全部 3/3 成功（基线 0/3）；关键消融：随机课程 **−93%**、去自验证 **−73%**、GPT-3.5 代码生成少 **5.7×**。
