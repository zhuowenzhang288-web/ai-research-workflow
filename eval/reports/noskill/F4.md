# IDEA_REPORT：评测 self-evolving / 自我改进 LLM agent 的 3 个 benchmark

> 核验说明：以下 arXiv 编号与分数均直接来自 arXiv 官方摘要页（arxiv.org/abs/...），2026-11-17 逐条核验。
> 这 3 个 benchmark 均为 self-evolving agent 文献（记忆增强、经验回放、轨迹自我改进的 web / computer-use / SWE agent）中最常用的评测载体。

---

## 1. SWE-bench

1. **名称 / 编号**：SWE-bench: Can Language Models Resolve Real-World GitHub Issues? —— **arXiv:2310.06770**（ICLR 2024）
2. **测什么**：给 LLM agent 一个真实 Python 代码库 + GitHub issue 描述，要求自主修改代码使 issue 被解决。共 **2,294 个**来自 12 个真实仓库的 issue/PR 对，考察长上下文理解、跨文件编辑、与执行环境交互等能力——是自我改进型编码 agent（从轨迹/反馈中学习的 SWE agent）的标准评测。
3. **代表分数**（原文摘要，已核验）：原论文评测中表现最好的模型 **Claude 2 仅能解出 1.96%** 的 issue（2023 年 10 月 v1 结果）。
   - 注：后续 SWE-bench Verified（OpenAI 人工筛选的 500 题子集）上 Claude 3.5 Sonnet 达 49%，此数字本报告未在本次核验中二次确认，仅供参考。

## 2. WebArena

1. **名称 / 编号**：WebArena: A Realistic Web Environment for Building Autonomous Agents —— **arXiv:2307.13854**
2. **测什么**：自托管的**真实可复现网站环境**（电商、Reddit 论坛、GitLab、CMS 四类站点 + 工具与知识库），**812 个**长程、功能正确性可自动判定的 web 任务；广泛用于评测能从经验中积累网页操作技能的 self-evolving web agent。
3. **代表分数**（原文摘要，已核验）：最佳 **GPT-4 agent 端到端任务成功率仅 14.41%**，人类为 **78.24%**。

## 3. OSWorld

1. **名称 / 编号**：OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments —— **arXiv:2404.07972**
2. **测什么**：首个可扩展的**真实操作系统环境**（Ubuntu / Windows / macOS 上的真实 Web 与桌面应用），**369 个**开放式计算机任务，每个任务带初始状态配置与基于执行的评测脚本；是 self-evolving computer-use agent（从交互经验中改进 GUI 操作）的主流 benchmark。
3. **代表分数**（原文摘要，已核验）：人类可完成 **72.36%** 的任务，而当时**最佳模型仅 12.24%** 成功率，瓶颈主要在 GUI grounding 与操作知识。
