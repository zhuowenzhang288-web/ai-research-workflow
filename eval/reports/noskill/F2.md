## 1. VQAv2 (test-dev)：86.5（Molmo-72B）

- **86.5** — Molmo-72B，来源：*Molmo and PixMo: Open Weights and Open Data for State-of-the-Art Vision-Language Models*，**arXiv:2409.17146**（v2, 2024-12），Table 1，"VQA v2.0 testdev" 列。
- 对照（同一表格，便于交叉验证）：PaLI-X 86.0（test-dev；其论文正文称 test-std 86.1），**arXiv:2305.18565** Table 1；Gemini 1.5 Pro 80.2、GPT-4o 78.7、Claude 3.5 Sonnet 70.7、LLaVA-OneVision-72B 85.2、InternVL2-Llama3-76B 85.6。
- 注意事项：86.5 为 Molmo 作者在论文中自报的测试结果（使用 36 crops 推理配置），并非来自 EvalAI 官方榜单页面；PaLI-X 的 86.0/86.1 是此前长期被广泛引用的该榜单最高数字。

## 3. TextVQA (test)：80.78（PaLI-X；PaLI-3 持平）

- **80.78** — PaLI-X（使用 GCP Vision API 外部 OCR 输入），来源：*PaLI-X: On Scaling up a Multilingual Vision and Language Model*，**arXiv:2305.18565**，Table 2；论文注明 TextCaps/TextVQA/InfographicVQA/DocVQA 均经官方评测服务器评测（即 test 集）。
- **80.78** — PaLI-3（同样外接 OCR 输入，持平 PaLI-X），来源：*PaLI-3 Vision Language Models: Smaller, Faster, Stronger*，**arXiv:2310.09199**，Table 2（同注明官方评测服务器）；**不使用外部 OCR 时 PaLI-3 为 79.51**（端到端）。
- 重要口径提醒：近年常被引用的更高 TextVQA 数字多为 **val 集**，不能与本题的 test 集直接比较，例如：
  - Qwen2-VL-72B **85.5**（val，论文表格明确标注 TextVQA_val），来源 **arXiv:2409.12191** Table 2；
  - Molmo-72B **83.1**（val），来源 arXiv:2409.17146 Table 1。
- 因此在 test 集口径下，本次可核验的最高值为 **80.78**；若接受 val 集口径，则 Qwen2-VL-72B 的 85.5 是可核验的更高数字（已标注口径差异）。
