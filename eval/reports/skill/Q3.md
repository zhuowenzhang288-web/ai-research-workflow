# IDEA_REPORT：Voyager 拆论文

## 1. 文献信息
- **标题**：Voyager: An Open-Ended Embodied Agent with Large Language Models（arXiv:2305.16291，v1 2023-05-25 / v2 2023-10-19；后录 TMLR 2024）
- **作者**：Guanzhi Wang*, Yuqi Xie*, Yunfan Jiang, Ajay Mandlekar, Chaowei Xiao, Yuke Zhu†, Linxi Fan†, Anima Anandkumar（Caltech / UT Austin / ASU / NVIDIA / Stanford）
- **链接**：https://arxiv.org/abs/2305.16291 ，代码 https://voyager.minedojo.org/
- **问题**：在 Minecraft 中构建无需人工干预、持续探索并积累技能的开放式具身终身学习智能体。
- **方法**：GPT-4 黑盒 prompting + 三模块——①自动课程（按探索进度自底向上提出任务）；②技能库（可执行代码，按 GPT-3.5 生成描述的 embedding 存入向量库，top-5 检索）；③迭代 prompting（环境反馈 + 执行错误 + GPT-4 自我验证，最多 4 轮即换任务）。

## 2. 数据与方法
- **环境**：MineDojo + Mineflayer JS API（高级控制原语，非像素输入）。无固定数据集，开放式探索。
- **模型**：gpt-4-0314（代码生成）、gpt-3.5-turbo-0301（辅助任务）、text-embedding-ada-002；温度 0（课程 0.1）。
- **基线**：ReAct、Reflexion、AutoGPT（作者将其改造适配 Minecraft）。
- **指标**：发现独特物品数、科技树解锁（以 prompting 迭代计）、行进距离、新世界零样本任务成功率（钻石镐/金剑/岩浆桶/指南针）；每项 3 次试验。

## 3. 主要结果与证据链（论文事实）
160 次迭代内发现 63 种独特物品（3.3×）；木/石/铁工具解锁快 15.3×/8.5×/6.4×，且唯一解锁钻石级（102 次迭代，仅 1/3 试验成功）；行进距离 2.3×（图 7）；零样本任务全解而基线全败，技能库可直接增强 AutoGPT（作者观点：即插即用）。消融：随机课程 −93% 物品；去技能库后期停滞；去自验证 −73%；GPT-4 比 GPT-3.5 多 5.7× 物品。

## 5. 局限性
- **作者声明**：GPT-4 成本高（15×）；仍会卡住失败、自验证偶发失效（如不识蜘蛛丝）；课程与代码生成有幻觉（"铜剑"、圆石当燃料、调用不存在 API）。
- **未明说（分析/推断）**：强依赖 GPT-4 及闭源 API，复现性受限；评测以迭代数而非 wall-clock/Token 成本计；自验证者与执行者同源，判据循环；各基线为 NLP 方法改造、偏弱，且未与 VPT/DreamerV3 等低层方法对比；"终身"仅约 160 迭代规模；GPT-4 预训练可能已含 Minecraft 知识，新颖性存疑。
