# Q4 争议地图：LLM Agent 长期记忆/经验管理

## 1. 共识区（多项独立研究支持）
- **纯长上下文"塞满"不可靠**：长对话 QA 上多数模型显著弱于带记忆系统（LoCoMo 2024；LongMemEval 2025；覆盖 GPT-4o/Claude/Llama）。
- **记忆类型应分离**：情景/语义/程序记忆分离组织优于单一池（Generative Agents 2023；Voyager 2023；Scarlett 2025）。
- **检索与更新是瓶颈**：召回噪声、stale 记忆、knowledge-update 类问题最难（LongMemEval）。
- **评测错位**：对话 QA 指标与 agent 行为改变的相关性未被证实（MERIT 2026 明确提出）。

## 2. 分歧区
**A. 记忆到底有多大用？**
- 正方：Mem0（LOCOMO 上 +~40% F1）、A-Mem（multi-hop F1 翻倍、6 个模型一致）、Scarlett 均报告显著提升。
- 反方：LoCoMo 原文中 ReadAgent/MemGPT 多数设置不及 full-context 基线；LongMemEval 显示记忆法仅在单会话召回有效，多会话/时间/更新类提升微小；MERIT（23,440 episodes、带成本核算）报告边际效用有限。
- 解释（**均为假设**）：①数据域——对话 QA vs 工具执行；②评测——F1 vs 行为改变；③预算——是否计入写/检/演化成本；④模型代差——2023 系统 vs 2024–25 强模型。

**B. 组织方式**：结构化图谱/Zettelkasten（Mem0、A-Mem）vs 平铺检索（MemGPT），各方均报告己方最优，但无统一基准公平对比。假设：写策略/检索器差异是混淆项，非结构本身。

**C. 遗忘机制**：MemoryBank 主张遗忘曲线必要；LongMemEval 显示遗忘/更新恰是最大错误源。假设：任务类型（陪伴 vs 事实更新）起调节作用。

## 3. 逐篇 Limitation / Future Work（未单列者注明）
- **A-Mem**（2502.12110，已核对 Limitation 节）：组织质量受底层 LLM 能力影响；仅文本，未来扩展多模态。
- **LongMemEval**：局限为仅对话 QA、英文、会话由 LLM 合成；未测记忆对下游行为的影响（据训练知识，未逐字核对原文）。
- **LoCoMo**：局限为 QA 式评测、英文、依赖 LLM 判分（同上）。
- **Mem0**：工程系统论文，未单列 Limitation 节；评测集中于 LOCOMO。
- **MemOS**（2505.22101，已核对摘要）：框架提案，未见独立 Limitation 节。
- **HELMET**（评测证据，非记忆系统）：未单列 limitation；结论是合成任务（NIAH）不能预测真实任务表现。
- **MERIT**（2026，已核对摘要）：pilot 仅 2 个模型、3 个域。

## 4. 空白值不值做？能否切入？
值得做（按优先级）：
1. **成本感知的记忆效用/写策略评测**：现有基准只测 F1；MERIT 仅为 pilot。数据（LoCoMo/LongMemEval/MERIT）公开，API 预算即可切入。
2. **记忆演化/自更新的错误传播与抗污染**：A-Mem 式演化无正确性保障；受控 corruption 研究刚起步。
3. **可学习的写策略（what/when to write）**：现有系统全为人工启发式；可在现成记忆系统上用 bandit/RL 训练，单卡+API 可行。

风险：算力门槛低，但强基线迭代快，需绑定行为改变类评测，避免"评测刷分"。
