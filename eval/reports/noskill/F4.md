# F4 报告：3 个 self-evolving / 自我改进 LLM agent 评测 benchmark

> 核验方式：均通过 arXiv 官方全文 HTML 逐表核对（2026-11-16）。
> 说明：这三者都是"自动设计/进化 agent 系统"范式（meta-agent 自动搜索、进化或重写 agent 设计）的标准评测套件，分数来自各论文自报的官方结果表，非独立第三方 leaderboard。

---

## 1. AgentSquare（Modularized LLM Agent Search 评测套件）

- **名称 / 编号**：AgentSquare: Automatic LLM Agent Search in Modular Design Space，**arXiv:2410.06153**（已核验）
- **测什么**：把 LLM agent 设计抽象为 4 个模块（Planning / Reasoning / Tool Use / Memory）的模块化设计空间，评测"agent 自动搜索/进化"算法能否在 6 个 agent 任务上发现优于人工设计的 agent。任务覆盖 Web（WebShop）、具身（ALFWorld、ScienceWorld）、工具使用（M3ToolEval）、游戏/规划（PDDL）、旅行规划（TravelPlanner）。
- **代表分数**（Table 1，GPT-4o 执行，已核验）：搜索出的最优 agent 依次得分——WebShop **0.607**、ALFWorld **0.695**、SciWorld **0.781**、M3ToolEval **0.524**、TravelPlanner **0.583**、PDDL **0.669**；平均比最佳人工设计 agent 高 **17.2%**（对最佳人工基线的逐任务相对提升：WebShop +14.1%、ALFWorld +26.1%、SciWorld +20.5%、M3Tool +30.6%、TravelPlanner +6.0%、PDDL +6.0%）。作为参照，同表最佳人工基线 Self-refine 在 ALFWorld 仅 0.567，CoT 仅 0.405。

## 2. ADAS（Automated Design of Agentic Systems 的 meta 评测）

- **名称 / 编号**：Automated Design of Agentic Systems（ADAS，算法名 Meta Agent Search），**arXiv:2408.08435**（已核验）
- **测什么**：评测 meta-agent 能否通过"编程新的 agent 代码"实现自我改进。评测域包括 DROP（阅读理解）、MGSM（多语言数学）、GPQA（科学）、MMLU（多任务）以及 ARC 式任务；并测试搜索出的 agent 跨域/跨模型迁移能力。
- **代表分数**（已核验，95% bootstrap 置信区间）：
  - 域内（正文 Table 1 结论）：数学域（MGSM）准确率较最佳手工 agent **+14.4%**，DROP F1 **+13.6**；
  - 跨域迁移（附录 Table 4，MGSM 上搜索出的 top agent 迁移到数学域）：最优 agent "Dynamic Role-Playing Architecture"在 GSM8K **69.5±3.2%**（CoT 基线仅 34.9%，最佳手工基线 LLM-Debate 43.6%，即 +25.9%）、GSM-Hard **31.2±3.2%**、SVAMP **81.5±2.6%**、ASDiv **91.8±1.8%**；搜索 agent 在 MGSM 本身达 **53.4±3.5%**（最佳手工基线 LLM-Debate 39.0%）。执行模型 GPT-3.5-turbo，meta agent 为 GPT-4o。

## 3. AFlow（自动化 agentic workflow 生成的评测套件）

- **名称 / 编号**：AFlow: Automating Agentic Workflow Generation，**arXiv:2410.10762**（已核验）
- **测什么**：把 workflow 优化形式化为对"代码表示的 workflow 图"的搜索（MCTS + 执行反馈），在 6 个公开数据集（GSM8K、MATH、HotpotQA、DROP、HumanEval、MBPP）上评测自动进化出的 workflow，指标分别为 solve rate / F1 / pass@1。
- **代表分数**（Table 1，executor 为 GPT-4o-mini，测试集平均 3 次，已核验）：GSM8K **93.5%**、HumanEval **94.7**、MBPP **83.4**、HotpotQA **73.5**（F1）、DROP **80.6**（F1）、MATH **56.2%**，六项平均 **80.3%**；比手工设计方法平均 **+5.7%**，比同期自动 workflow 优化方法（如 ADAS 基线：GSM8K 90.8、MATH 35.4）平均 **+19.5%**。另：消融显示无人工 operator 时 AFlow 在 GSM8K 仍达 93.1%。
