# IDEA_REPORT：Voyager 拆论文

## 1. 文献信息
**标题**：Voyager: An Open-Ended Embodied Agent with Large Language Models（[arXiv:2305.16291](https://arxiv.org/abs/2305.16291)，v1 2023-05-25 / v2 2023-10-19）。
**作者**：Wang, Xie, Jiang, Mandlekar, Xiao, Zhu, Fan, Anandkumar（Caltech/UT Austin/NVIDIA/Stanford/ASU）。
**问题**：在 Minecraft 开放世界中构建无人工干预、持续探索并终身积累技能的具身智能体。
**方法**：纯提示调用 blackbox GPT-4（不微调）三模块——①自动课程：GPT-4 按当前状态与成败记录提出渐进任务；②技能库：技能=可执行代码，按 GPT-3.5 生成的描述嵌入（ada-002）存向量库并检索复用；③迭代提示：融合环境反馈、执行错误与自验证（另一 GPT-4 当 critic）循环改代码，卡住 4 轮换任务。

## 2. 数据与方法
**环境**：MineDojo + Mineflayer JS API（高层控制，非像素级）。**模型**：gpt-4-0314（课程温度 0.1，其余 0）、gpt-3.5-turbo-0301、text-embedding-ada-002。
**基线**：ReAct、Reflexion、AutoGPT（改造为可执行版本）。
**指标**：160 次 prompting 迭代内不重复物品数；科技树里程碑达成迭代数（3 次均值）；地图移动距离；新世界零样本任务（钻石镐/金剑/岩浆桶/指南针，50 迭代内成功率）。

## 3. 主要结果与证据链
（结果，§3.3/表1/2）发现 63 种物品（3.3×）；解锁木/石/铁工具快 15.3×/8.5×/6.4×，唯一达钻石级（1/3 次，102 迭代）；行程 2.3×；新世界 4 任务全 3/3，基线 0/3；技能库移植 AutoGPT 后部分成功，可即插即用。消融（图9）：随机课程 −93%、去自验证 −73%、换 GPT-3.5 代码 −5.7×。（作者观点）代码即动作空间使技能可组合、抗灾难遗忘。

## 5. 局限性
**作者声明**：①GPT-4 成本为 GPT-3.5 的 15×；②仍会卡壳，自验证偶失效（如不识蜘蛛丝）；③幻觉：课程提出不存在物品（铜剑），代码误用圆石作燃料、调用不存在 API；④仅有文本 GPT-4，无视觉感知；寄望更强 API 与开源模型微调。
**未明说（分析/推断）**：①成败由 GPT-4 自评，生成与评测同源，有循环论证风险；②3 次试验方差大（AutoGPT ±72），统计功效弱；③回避与 VPT/DreamerV3 对比，动作空间差异未量化；④以迭代数为效率单位，忽略时延/费用差异；⑤"唯一解锁钻石"仅 1/3 成功，与"持续稳定进步"叙事有张力；⑥技能库规模化后的检索退化与错误技能累积未评估。
