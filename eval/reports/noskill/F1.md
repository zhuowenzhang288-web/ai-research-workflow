# F1 探针报告：LLM Agent 长期记忆/经验管理方向（2025–2026）

> 核验方式：以下每篇均通过 arXiv 官方页面（arxiv.org/abs 全文或 export.arxiv.org API）逐一核验，
> 核验日期：2026-11-17。所有数字直接抄录自论文摘要或正文，未凭印象编写。

## 5 篇代表性工作

### 1. Zep: A Temporal Knowledge Graph Architecture for Agent Memory
- **arXiv**：2501.13956（2025 年 1 月提交）
- **第一作者**：Preston Rasmussen
- **关键数字**：在 MemGPT 团队提出的 Deep Memory Retrieval (DMR) 基准上，Zep 得分 **94.8%，高于 MemGPT 的 93.4%**；在 LongMemEval 上准确率最高提升 **18.5%**，同时响应延迟降低 **90%**。
- 要点：核心组件 Graphiti 是时间感知知识图谱引擎，支持对话/业务数据的动态建图与时序关系维护。

### 2. A-MEM: Agentic Memory for LLM Agents
- **arXiv**：2502.12110（2025 年 2 月提交，NeurIPS 2025 接收）
- **第一作者**：Wujiang Xu
- **关键数字**：在 DialSim 基准上 F1 达 **3.45**，比 LoCoMo 方法（2.55）高 **35%**、比 MemGPT（1.18）高 **192%**；记忆操作约 1,200 token，较基线（约 16,900 token）降低 **85–93%**。
- 要点：借鉴 Zettelkasten 卡片笔记法，记忆以结构化 note 形式自主建立链接（link generation）并随新经验演化（memory evolution），无需预定义记忆操作。

### 3. Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory
- **arXiv**：2504.19413（2025 年 4 月提交）
- **第一作者**：Prateek Chhikara
- **关键数字**：LOCOMO 基准上 LLM-as-a-Judge 指标相对 OpenAI memory **提升 26%**；p95 延迟降低 **91%**，token 成本节省 **超过 90%**。
- 要点：可扩展的记忆提取-整合-检索架构，并有图记忆变体（Mem0g）建模实体关系。

### 4. MemoryOS（Memory OS of AI Agent）
- **arXiv**：2506.06326（2025 年 5–6 月）
- **第一作者**：Jiazheng Kang
- **关键数字**：在 LoCoMo 基准（GPT-4o-mini）上，相对基线平均提升 **F1 +49.11%**、**BLEU-1 +46.18%**。
- 要点：仿操作系统内存管理，设计短/中/长期三级存储（对话链 FIFO 升级 + 分段页式长期个人记忆）及存储/更新/检索/生成四模块。
- 备注：网上流传的副标题 "Enhancing LLM-based Agents with Transparent Memory" 经核验**不符**，论文实际标题即 "Memory OS of AI Agent"。

### 5. MemOS: A Memory OS for AI System
- **arXiv**：2507.03724（2025 年 7 月提交）
- **第一作者**：Zhiyu Li（MemTensor 等 39 位作者）
- **关键数字**：KV-based 记忆注入使 Qwen2.5-72B 在长上下文场景 **TTFT 降低 91.4%**；鲁棒性评测中在 **100 QPS 压力下保持 100% 成功率**；在 LoCoMo / LongMemEval / PreFEval / PersonaMem 四基准上整体均排名第一（同基座 GPT-4o-mini 下对比 MIRIX、Mem0、Zep 等）。
- 要点：将记忆视为可调度系统资源（MemCube 为基本单元），统一明文记忆、激活记忆、参数记忆三类记忆的表示、调度与演化。
