# Voyager 论文拆解报告

## 1. 文献信息
- **标题**：Voyager: An Open-Ended Embodied Agent with Large Language Models
- **作者**：Guanzhi Wang, Yuqi Xie, Yunfan Jiang, Ajay Mandlekar, Chaowei Xiao, Yuke Zhu, Linxi "Jim" Fan, Anima Anandkumar（UT Austin / NVIDIA / Caltech / UW Madison / Stanford）
- **版本/日期**：arXiv:2305.16291，v1 2023-05-25，v2 2023-10-19
- **链接**：https://arxiv.org/abs/2305.16291 ；代码 https://voyager.minedojo.org/
- **问题**：构建无需人工干预、能持续探索并积累技能的开放式具身智能体（Minecraft 终身学习）。
- **方法**：GPT-4 黑盒提示 + 三大组件——自动课程（automatic curriculum）、技能库（可执行代码 + 向量检索）、迭代提示机制（环境反馈/执行错误/自验证）。代码即动作空间，无需微调参数。

## 2. 数据与方法
- **环境**：MineDojo + Mineflayer JS API（文本状态：背包、附近实体、biome、时间、生命值等）。
- **模型**：gpt-4-0314（代码生成、课程、验证）、gpt-3.5-turbo（描述生成/问答）、text-embedding-ada-002（检索）；温度 0（课程 0.1）。卡死 4 轮换任务，上限 160 次提示迭代。
- **基线**：ReAct、Reflexion、AutoGPT（作者将其 NLP 方法改造进 Minecraft；未与 VPT/DreamerV3 等像素级 RL 直接对比）。
- **评测指标**：独特物品数、科技树解锁迭代数（木→石→铁→钻）、地图遍历距离、未见任务零样本成功率；每项 3 次试验取均值。

## 3. 主要结果与证据链
- 160 次迭代内发现 **63 种独特物品（3.3×）**（Fig.1）；木/石/铁工具解锁快 **15.3×/8.5×/6.4×**，且**唯一解锁钻石层级**（Table 1：6/11/21 次 vs AutoGPT 92/94/135 次，3/3 成功）；遍历距离 **2.3×**（Fig.7）。
- 新地图零样本任务（钻镐/金剑/岩浆桶/指南针）Voyager 全部 3/3 成功（18–21 次迭代），基线 0/3；技能库移植给 AutoGPT 后部分任务成功——证明技能库可插拔复用（Table 2, Fig.8）。
- 消融（Fig.9）：随机课程 −93% 物品；去自验证 −73%；GPT-3.5 比 GPT-4 少 5.7× 物品；附录显示对 gpt-4-0613 鲁棒。
- 区分：以上"3.3×/15.3×"为**实测结果**；"课程模拟内在好奇心""技能组合缓解灾难性遗忘"等为**作者观点**。

## 5. 局限性
**作者声明**：① 成本高（GPT-4 贵 15×，开源模型达不到）；② 仍会卡死失败，自验证偶有漏判（如击败蜘蛛未识别掉线）；③ 幻觉——课程提出不存在的"铜剑"，代码用圆石作燃料、调用不存在的 API。

**分析/推断（未明说）**：① 基线均为 NLP 方法移植，非原生 Minecraft 智能体，且排除 VPT/DreamerV3，优势可能部分来自基线不适配；② 仅 3 次试验，方差大（AutoGPT ±72），统计效力弱；③ 依赖特权文本状态，无视觉感知，"具身"程度打折；④ 终身学习实为外挂向量库，非参数级知识积累，遗忘结论需谨慎；⑤ 迭代数作为效率指标与 API 费用挂钩，未报告实际成本/墙钟时间；⑥ 仅在单一沙盒验证，机器人迁移（Broader Impacts 提及）未经实验；⑦ 强依赖提示工程，提示质量未做消融。
