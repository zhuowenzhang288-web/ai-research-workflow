# F4 探针：3 个 self-evolving / 自我改进 LLM agent benchmark

核验说明（2026-11-17）：以下编号均经实际访问 arxiv.org 摘要页核对标题一致（✓）；
分数均直接转录自论文摘要/正文页面，未凭记忆填写。存疑处已标注。

## 1. RSIGym — A Flexible Environment for Recursive Self-Improvement

- **arXiv**：**2610.10310** ✓（2026-10 挂出）
- **测什么**：**最对口的"递归自我改进"（RSI）评测**：agent 利用反馈跨任务闭合自身能力差距，提出统一指标 RSI-Index（跨 5 个 benchmark 闭合性能差距的比例），以 Joint 改进轨道衡量 agent 是否真的能"自我进化"。
- **代表分数**：Opus 5 的 **RSI-Index = 0.4809**（$500 预算）；其中 SWE-bench Verified **17.67% → 50.33%**、AIME **31.67% → 97.78%**。
- **来源**：https://arxiv.org/abs/2610.10310
- **存疑**：2026-10 新论文、未见同行评审标注；分数取自摘要层，未下沉正文表格复核。

## 2. Agents of Change — Self-Evolving LLM Agents for Strategic Planning

- **arXiv**：**2506.04651** ✓（Belle et al.，UCSB 等；**非** Google DeepMind 的同名 benchmark——后者查不到/未能核验）
- **测什么**：评测**自我进化 LLM agent** 在长程战略决策中的表现：提出的方法 HexMachina 在《卡坦岛》（Settlers of Catan）中通过进化机制持续自我改进，对抗搜索式强基线。
- **代表分数**：HexMachina 对最强人工基线 AlphaBeta 取得 **54% 胜率**。
- **来源**：https://arxiv.org/abs/2506.04651
- **存疑**：单环境（Catan）方法论文，泛化性有限；54% 为摘要口径。

## 3. RE-Bench — Evaluating frontier AI R&D capabilities of language model agents against human experts

- **arXiv**：**2411.15114** ✓（METR）；相关长任务论文 *Measuring AI Ability to Complete Long Software Tasks*：**2503.14499** ✓
- **测什么**：7 个开放式 ML 研究工程任务，agent 在给定预算（2h/8h/32h）内**迭代改进自己的方案**（归一化得分 0–1），与 61 位人类专家共 71 次 8 小时尝试的基线对比——"自我改进"的典型评测设置。
- **代表分数**：① 2 小时预算下最佳 AI agent 得分是人类专家的 **4 倍**；8 小时预算人类反超；32 小时预算人类得分是最佳 agent 的 **2 倍**。② 得分最高的两个配置 **o1-preview (AIDE)** 与 **Claude 3.5 Sonnet (20241022, Modular)** 仅相当于人类专家的第 **36、37 百分位**。③ 长任务论文合并 horizon（非 RE-Bench 单独）：o3 ≈ **110 分钟**、Claude 3.7 Sonnet ≈ **50 分钟**（50% 成功率口径）。
- **来源**：https://arxiv.org/abs/2411.15114 ；https://arxiv.org/abs/2503.14499
- **存疑**：time-horizon 是三个任务套件（HCAST+RE-Bench+SWAA）**合并**拟合指标，不能当作 RE-Bench 单独成绩；v1/v4 摘要数字不同（模型集更新），引用需标版本。
