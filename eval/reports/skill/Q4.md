# 争议地图：LLM Agent 长期记忆/经验管理

检索：经 arXiv 官方页核验 13 篇（更正两处编号：综述为 2404.13501，LongMemEval 为 2410.10813）。仅核摘要页，全文 Limitations 未通读，相关条目标【未核验】。

## 1. 共识区（多项独立支持 + 适用范围）
- 跨会话记忆普遍失败：LoCoMo、LongMemEval、MemoryAgentBench 三个独立基准结论一致（适用：对话助手，≥35 sessions 长程）。
- 结构化/分层记忆优于平铺 RAG：MemGPT、A-MEM、Zep、MemoryOS 四条独立路线自报一致增益（适用：各自基准；均未经第三方复现）。
- 写入须伴随遗忘/更新：MemoryBank、LongMemEval、MemoryAgentBench 收敛到同一结论。
- 语言化反思可作经验回放：Reflexion、Generative Agents 等多篇独立支持（适用：短程任务）。

## 2. 分歧区（证据 + 解释；解释均为我方假设，未验证）
- 记忆是否净有益：建设派（A-MEM/Zep 默认增益为正）vs 对抗派（MINJA：记忆可被注入投毒；LongMemEval：设计不当的记忆反噬）。"净收益为负的条件"无人正面回答。假设：增益集中在检索密集任务，负收益集中在安全敏感/知识冲突任务。
- 长上下文 vs 外置记忆：受控研究（2409.12181）表明窗口≠记忆且外推困难，产业实践仍两路并存。假设：分歧源于预算——外置记忆在超长程省 token，代价是检索误差。
- 架构对立：时序图谱（Zep）vs OS 分层（MemGPT/MemoryOS）各自在自选基准自报 SOTA，缺公平对比。假设：差异部分来自基准选择而非架构本身。
- 自报增益可信度：Zep（DMR +18.5%）、MemoryOS（LoCoMo F1 +49%）均无独立复现；LoCoMo 被多方复用，相对可信。

## 3. 逐篇 Limitation / Future Work（无单列者注明，未编造）
- Generative Agents、Reflexion、Zep、MemoryOS：原文无单列 Limitation 段【未核验】。
- A-MEM：批评固定结构限制记忆适应性【摘要】；自 limitation 未核验。
- MemGPT：仅 2 个评测域【摘要】。
- MemoryBank：实验以 ChatGPT 模拟对话为主【摘要】；遗忘曲线参数固定。
- LoCoMo / LongMemEval：基准即证据——长上下文+RAG 显著落后人类；后者报跨会话准确率降约 30%。
- 综述（2404.13501）：末节列局限与展望，具体条目全文未核验。
- MINJA：记忆库是攻击面，投毒防御阙如【摘要】。
- MemoryAgentBench：现有方法无一掌握全部四项记忆能力（含选择性遗忘）【摘要】。

## 4. 候选空白（均源自上列 limitation/基准暴露问题，非"未检索到"断言）
选择性/受控遗忘的可操作方法；记忆安全与治理（投毒防御、可删除、来源审计）；冲突知识检测与更新；跨架构统一第三方 leaderboard；"记忆净收益为负"的条件刻画。

## 5. 判定
空白值得做：选择性遗忘 + 安全治理受共识区三处与 MINJA 独立驱动，无主导方法。现有条件可切入：LoCoMo、LongMemEval、MemoryAgentBench 均公开；算力轻（记忆为推理期组件，分钟级实验）；路径清晰（在 MemGPT/A-MEM 强基线上加遗忘/防御模块做受控消融）。风险：评测易受基线选择污染，须预设统一评测协议。
